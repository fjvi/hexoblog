# Your HexoLaunch blog

This repository contains your blog, articles, images, settings, and deployment
workflow. You own it. HexoLaunch manages it only while you keep the GitHub App
connected.

日常写作和设置请使用 HexoLaunch 管理后台。这个仓库保存你的博客、文章、图片、设置
和自动发布流程，所有内容归你所有。即使不再使用 HexoLaunch，仓库也不会被平台删除。

Draft files under `source/_drafts` are not published to the website, but this
repository is public, so their source can still be viewed on GitHub.

`source/_drafts` 中的草稿不会出现在博客上，但本仓库是公开的，因此草稿源码仍可能
被他人看到，请勿保存密码或隐私信息。
